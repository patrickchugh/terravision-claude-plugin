# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue.

- Use GitHub's "Report a vulnerability" button on the Security tab of https://github.com/patrickchugh/terravision, or
- email p.chugh@neogeno.com with the details and steps to reproduce.

You should receive an acknowledgement within five working days. Please allow time for a fix to be released before disclosing the issue publicly.

## Scope

This repository contains the Claude plugin manifest and skill for TerraVision. The TerraVision program itself lives at https://github.com/patrickchugh/terravision, and reports about it are welcome through the same channels.

## Supported versions

Only the latest release of the plugin and of TerraVision receives security fixes.
